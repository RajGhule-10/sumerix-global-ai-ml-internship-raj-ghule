# Task 2 - Feature Engineering, Model Optimization & Performance Comparison

## Objective
Compare multiple regression models using the California Housing Dataset and identify the best-performing model.

## Models Evaluated
- Linear Regression
- Ridge Regression
- Decision Tree Regressor

## Results

| Model | RMSE | R² Score |
|---------|---------|---------|
| Decision Tree | 0.724 | 0.600 |
| Ridge Regression | 0.746 | 0.576 |
| Linear Regression | 0.746 | 0.576 |

Decision Tree Regressor
